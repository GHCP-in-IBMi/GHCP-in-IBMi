# IBM i source lookup

- When searching for IBM i source content, always check `<USERPROFILE>\docs\ibmi\` first in its dedicated source-file folder (for example, `<SRCF>\<MBR>.<TYPE>.md`). Treat that documentation as the primary source.
- If the source documentation is not there, do not search the IBM i system for source content; instead follow `ibmi-member-opening.instructions.md` to retrieve its metadata and open it.
